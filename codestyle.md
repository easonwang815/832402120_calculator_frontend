# Code Style

These project rules are based on the [Google JavaScript Style Guide](https://google.github.io/styleguide/jsguide.html) and the [Google HTML/CSS Style Guide](https://google.github.io/styleguide/htmlcssguide.html). I use four spaces for indentation in this project.

## JavaScript

- Use `const` for values that do not change and `let` for values that change.
- Use names such as `loadHistory` and `currentPage`.
- Use uppercase names for constants, such as `PAGE_SIZE`.
- Use single quotes and end statements with semicolons.
- Use braces for conditions and loops.
- Keep functions small and give each one a clear job.
- Use `async` and `await` for API requests.
- Add events with `addEventListener`.
- Show returned text with `textContent`.

## HTML and CSS

- Use four spaces for indentation.
- Use double quotes for HTML attributes.
- Use lowercase names with hyphens for IDs and CSS classes.
- Use buttons for actions and lists for history records.
- Write one CSS property per line.
- Group CSS rules by page section.

## Comments

Write short English comments for the main steps. Explain code that is hard to follow rather than every line.
